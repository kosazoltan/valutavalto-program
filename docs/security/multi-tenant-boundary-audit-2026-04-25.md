## Részletes igazolás

### CashDeskBreak (JAVITVA)

```java
// CashDeskBreakRepository.java
@Query("""
    SELECT b FROM CashDeskBreak b
    WHERE b.cashDeskId IN (
        SELECT cd.id FROM CashDesk cd WHERE cd.companyId = :companyId
    )
    ORDER BY b.breakStart DESC
""")
List<CashDeskBreak> findByCompanyIdOrderByBreakStartDesc(@Param("companyId") UUID companyId);
```

A `CashDeskBreak.cashDeskId` UUID-jét a `CashDesk.id` => `CashDesk.companyId` join-on át szűri. Ez biztosítja, hogy egyetlen tenant break-jei sem szivároghatnak más tenant-be.

A `CashDeskBreakService.listBreaks(null)` mostantól `SecurityUtils.getCurrentCompanyId()`-t hív, és csak az aktív tenant break-jeit listázza.

Ennek a globális status-nak a dokumentálása: a `CurrencyRepository`-ben a `findAll()` metódus minden tenant számára közös eredményt ad, és **ez szándékolt**.

## Open items (külön sprint-be terelve)

### CommissionRate multi-tenant scope (P2)

A `CommissionRate` entitás jelenleg nem rendelkezik `companyId` mezővel. A jutalék-arányok elvileg cég-specifikusak (az EBC Zrt. saját jutalék-szabályzat alapján), de a jelenlegi DB séma ezt globálisként tárolja.

**Megoldási javaslat (külön PR)**:

1. Flyway migráció `V164__commission_rate_multi_tenant.sql`:
   ```sql
   ALTER TABLE commission_rate ADD COLUMN company_id UUID;
   UPDATE commission_rate SET company_id = (SELECT id FROM company WHERE code = 'EBC') WHERE company_id IS NULL;
   ALTER TABLE commission_rate ALTER COLUMN company_id SET NOT NULL;
   CREATE INDEX idx_commission_rate_company ON commission_rate(company_id);
   ```

2. `CommissionRate` entitás kibővítése `companyId` mezővel + `@JoinColumn`.

3. `CommissionRateRepository.findByIsActiveTrueOrderByValidFromDesc()` →
   `findByCompanyIdAndIsActiveTrueOrderByValidFromDesc(UUID companyId)`.

4. `CommissionRateService` minden metódus `SecurityUtils.getCurrentCompanyId()` hívással bővítve.

**Érintett fájlok**: `CommissionRate.java`, `CommissionRateRepository.java`, `CommissionRateService.java`, `CommissionRateController.java`, plus mindegyik test-mock.

**Becsült munka**: 1 sprint-fél nap (kód) + DB migráció + integration test.
