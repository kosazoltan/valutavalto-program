# Valutavalto Obsidian Vault

Ezt a vault-ot Obsidian-ban lehet megnyitni (File -> Open folder as vault).
Automatikus backlink + tag-rendszer.

## Struktura

- `MANDATE_V2.md` - AKTIV: Multi-modell GitHub/PUSH minosegbiztositasi v2
- `MANDATE_V1_SUPERSEDED.md` - Archivum
- `PR_INDEX.md` - PR-ek idorendben
- `SKILLS_INDEX.md` - .claude/skills/ skillek
- `TAGS.md` - tag-definiciok
