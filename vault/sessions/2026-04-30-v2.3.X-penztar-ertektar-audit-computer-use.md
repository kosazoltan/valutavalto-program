## Szerepkör-ellenőrzés

A jelenlegi user (felhasznáo név: U) **pénztáros + értéktáros** kombinált jogkörrel rendelkezik a SetupWizard "FŐÉRTÉKTÁR" telepítési módban. Az "Adminisztráció" menü (UserManagement, BranchAccess matrix, BR config) — DIRECTOR szerepkört igényel, ezzel a user-rel NEM elérhető.

**A B7 audit fix kód-szinten verifikálva**:
- `backend/src/main/java/hu/puzzleir/valuta/service/ReceiptSequenceService.java:91`
- Format: `%s%s%06d` = prefix(1-2 char) + branchCode(3 digit) + sorszám(6 digit)
- BUY → "V", SELL → "E", CONVERSION → "K", TRANSFER_OUT → "AA", TRANSFER_IN → "AV", WU → "W", MG → "M", VIGNETTE/PHONE/OTHER → "X", PARTIAL_REFUND → "PR"
- `extractBranchCode()`: numerikus rész % 1000, paddelve %03d
- Példa: BR017 BUY → "V017000001" ✅
