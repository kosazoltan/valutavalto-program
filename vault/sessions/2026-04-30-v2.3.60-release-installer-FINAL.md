## Lessons learned (final)

1. **Autonóm session limits**: a Sourcery feedback loop könnyen ~5-6 PR után csökkenő hozam. **Maximum 5 PR / autonóm session** ajánlott a future-ban.
2. **Tool selection**: `Claude_in_Chrome` (USER's browser, shared auth) vs `MCP_DOCKER` (isolated Playwright) — **különbség kritikus** auth-protected pageek tesztjéhez.
3. **Batch-fix > drip-fix**: 37 ékezet-hiba 1 PR-ben (v2.3.60) hatékonyabb mint 37 separate PR.
4. **Defense-in-depth security**: orphan FK + null-check + standardized log code + redacted tenant IDs — **mind szükséges** OWASP-compliant multi-tenant isolation-höz.
5. **Industry-pattern docs**: a `D:/valutavalto-vault/references/` mappa mostantól reusable design-doc folder (b6-setupwizard-branch-mismatch-design.md, v2.4-sprint-roadmap.md).
