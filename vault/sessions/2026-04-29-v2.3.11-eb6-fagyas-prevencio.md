## E-B6 renderer fagyás 4-rétegű prevenció

### E-B6.1 Axios global timeout 15s
- **Hely:** `frontend-react/src/services/api/client.ts`
- **Fix:** `axios.create({ timeout: 15_000 })` — minden axios kérés MAX 15 sec, utána ECONNABORTED
- **Korábban:** NEM volt timeout → Hetzner 504 / lassú endpoint blokkolhatta a renderer event-loop-ot

### E-B6.2 Page Visibility API → sync-engine pause/resume
- **Renderer:** `frontend-react/src/App.tsx` figyeli a `visibilitychange` event-et
- **IPC:** `electronAPI.syncEnginePause()` / `syncEngineResume()`
- **Electron main:** `penztar-client/electron/main.ts` — új `ipcMain.handle('sync-engine-pause'|'sync-engine-resume')`
- **Preload:** `penztar-client/electron/preload.ts` exposelve
- **Types:** `frontend-react/src/types/electron.d.ts` interface bővítve

### E-B6.3 Error throttling exponenciális backoff
- **Hely:** `penztar-client/electron/sync-engine.ts`
- **Logika:** 3+ egymást követő failure → backoff 30s → 60s → 120s → max 300s (5 perc)
- **Reset:** sikeres run reseteli a `consecutiveFailures = 0`-ra
- **Diagnosztika:** új `getBackoffStatus()` metódus

### E-B6.4 Renderer heartbeat + window error catcher
- **Heartbeat:** `setInterval(() => logger.info('App', '[heartbeat] alive @ ...'), 60_000)` — fagyás-detection az electron-log fájlból
- **Error catcher:** `window.addEventListener('error', ...)` + `'unhandledrejection'` — néma JS hibák naplózása
