## ⚠️ Új finding — Heartbeat log production-ban CSEND

### Tünet
A v2.3.11 E-B6.4 heartbeat (`logger.info('App', '[heartbeat] alive @ ${ISO}')`) **production build-ben NEM jelenik meg a console-ban**.

### Root-cause
`frontend-react/src/utils/logger.ts`:
```typescript
const isDev = import.meta.env.DEV;
function shouldLog(level: LogLevel): boolean {
  if (isDev) return true;
  return level === 'warn' || level === 'error';  // info+debug PROD-ban CSEND
}
```

A `logger.info` csak DEV mode-ban emit. Production-ban CSAK warn+error log-olódik.

### Hatás
- A heartbeat teljesen eltűnik production-ban → a fagyás-detection NEM működik a deploy után
- A `setInterval(60_000, ...)` ugyan fut, de a `console.log` nem hívódik

### Hotfix v2.3.13-ba

**Opció A:** `logger.warn` használata heartbeat-nél (production-ban is fut)
```typescript
logger.warn('App', `[heartbeat] alive @ ${new Date().toISOString()}`)
```

**Opció B:** Direkt `console.log` használata (logger megkerülve)
```typescript
console.log(`[App] [heartbeat] alive @ ${new Date().toISOString()}`)
```

**Opció C:** Új `logger.heartbeat` szint (dedikált, mindig log-ol)
```typescript
heartbeat(tag: string, message: string): void {
  console.log(formatTag(tag), message);
}
```

A javaslat: **Opció A** (warn) — minimális változás + production-ban aktív.
