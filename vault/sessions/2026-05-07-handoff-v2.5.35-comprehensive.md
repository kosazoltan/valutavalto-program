## 1. Időrend — mit teljesítettünk

### Wave 1: SetupWizard + ESET retry (v2.5.27–v2.5.30)

**Probléma:** Helga laptop reinstall után nem tudott bejelentkezni, "status code 0"
hibákat kapott a napnyitásnál.

**Gyökér-okok:**
1. `AdminBootstrapService` reinstall esetén HTTP 400-at dobott, a kliens "alreadyDone"-t
   kezelt, a jelszó SOHA nem mentődött az adatbázisba.
2. Az `api:fetch` IPC handler 0x retry-vel rendelkezett — a login 3x retry-jét
   lemásoltuk, de a többi API hívás (napnyitás, role select) nem.

- v2.5.27 (`5ed88b2f`): `AdminBootstrapService.bootstrapAdmin()` reinstall esetén
  most frissíti a worker jelszavát ahelyett hogy 400-at dobna.

- v2.5.30 (`ce26305d`): SetupWizard `httpJsonWithRetry` wrapper — bootstrapAdmin,

## 4. Hibajegyzék (kritikus tanulságok)

### V190 partial index NOW() outage (2026-05-07 03:54)
- **Hatás**: production 502 ~17 percig
- **Root cause**: `WHERE attempt_at < NOW() - INTERVAL '30 days'` partial index
  predicate-ben — PostgreSQL `NOW()` nem IMMUTABLE függvény, tilos partial
  index-ben
- **Megelőzhető lett volna**: lokális PostgreSQL test-tel (a backend csak
  H2-vel tesztel, ami NEM ellenőrzi az IMMUTABLE constraint-et)
- **Tanulság**: alkalmazás-rétegben kell az időablakos cleanup-ot szűrni,
  NEM a partial index predicate-ben
- **Memory bejegyzés**: `vault/sessions/2026-05-06-hallucination-correction.md`
